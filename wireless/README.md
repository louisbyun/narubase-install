# NaruBase™ Wireless

**100% local wireless security monitoring — Wi-Fi & BLE, enterprise-approvable.**

</div>

---

This page hosts **installer downloads** for NaruBase™ Wireless — a Windows
desktop app that watches for new or unusual Wi-Fi and Bluetooth LE devices
nearby. Source code is private; see
[Releases](https://github.com/louisbyun/narubase-install/releases?q=wireless)
for the latest installer.

## What it does

- **Scans Wi-Fi and BLE** in your surroundings and keeps a local registry of
  known devices.
- **Alerts on new or unusual devices** — new hardware, odd hours, RSSI
  anomalies, or a fingerprint change on a previously seen device.
- **Watch mode** re-scans on an interval and fires native notifications.
- **Export** the device registry and alert history to JSON at any time.

## What it deliberately doesn't do

- **No cloud.** Scan data never leaves the machine.
- **No telemetry, no accounts.** License verification happens offline using
  an embedded Ed25519 public key.
