# MyGeneLog™

**Understand your own genome, entirely on your own machine.**

</div>

---

This page hosts **installer downloads** for MyGeneLog™ — a Windows desktop
app that parses a VCF file, or a 23andMe/AncestryDNA raw data export, and
matches it against a bundled reference dataset of published SNP-health
associations. Source code is private; see
[Releases](https://github.com/louisbyun/narubase-install/releases?q=mygenelog)
for the latest installer. Companion site: [mygenelog.com](https://www.mygenelog.com).

## What it does

- **Parses your genome file locally** — VCF, or a 23andMe/AncestryDNA raw
  export — nothing is uploaded, nothing leaves the machine.
- **Matches against a bundled reference dataset** of published SNP-health
  associations (a starting set, not a full ClinVar import).
- **Gates sensitive findings behind an explicit opt-in** — anything tied to
  a serious health condition (e.g. APOE/Alzheimer's risk, Factor V Leiden)
  stays hidden until you choose to reveal it, one at a time.
- **Informational only** — every result is framed as "published research
  associates this genotype with X," never a diagnosis, a predicted age of
  onset, or a medication recommendation.

## What it deliberately doesn't do

- **No cloud, no accounts.** Your genome file and analysis results never
  leave this machine.
- **No medical advice.** For anything it surfaces, talk to a doctor or a
  licensed genetic counselor — MyGeneLog is not a substitute for either.
