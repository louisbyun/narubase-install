# NaruBase™ Cloud

**Manage your cloud servers over SSH, with AI assistance — all from your own machine.**

</div>

---

This page hosts **installer downloads** for NaruBase™ Cloud — a Windows
desktop app for managing your own cloud servers over SSH, with an AI
assistant to help with commands. Source code is private; see
[Releases](https://github.com/louisbyun/narubase-install/releases?q=cloud)
for the latest installer.

## What it does

- **Connect directly to your own cloud providers** — bring your own API
  key, NaruBase Cloud talks to the provider's API directly.
- **SSH into your servers** and run commands with AI assistance.
- **Local-only credential storage** — your cloud provider API keys and SSH
  credentials are stored on your machine, not on a NaruBase server.

## What it deliberately doesn't do

- **No proxying.** NaruBase Cloud does not sit between you and your cloud
  provider's billing or infrastructure — you pay the provider directly.
- **No telemetry, no accounts.** License verification happens offline using
  an embedded Ed25519 public key.
