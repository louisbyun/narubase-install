# NaruBase™ Probe

**100% local network diagnostics, enterprise-approvable.**

</div>

---

This page hosts **installer downloads** for NaruBase™ Probe — a Windows
desktop app for diagnosing network, DNS, and TLS issues from your own
machine. Source code is private; see
[Releases](https://github.com/louisbyun/narubase-install/releases?q=probe)
for the latest installer.

## What it does

- **Diagnoses a target** (URL/host) across DNS resolution, TLS/certificate
  chain, and reachability, and explains what's wrong in plain language.
- **Bundled diagnostic cases** cover common failure patterns out of the box.
- **History** of past diagnoses, searchable and exportable.

## What it deliberately doesn't do

- **No cloud.** Diagnostic data (URLs, certificates, DNS answers) never
  leaves the machine.
- **No telemetry, no accounts.** License verification happens offline using
  an embedded Ed25519 public key.
